# Keyboard Shortcuts

This matches exactly what you'll see in the app itself under the toolbar's
**?** button (or <kbd>Ctrl/Cmd+/</kbd>).

| Shortcut | Action |
|---|---|
| <kbd>Ctrl/Cmd+O</kbd> | Open PDFs |
| <kbd>Ctrl/Cmd+Z</kbd> | Undo |
| <kbd>Ctrl/Cmd+Shift+Z</kbd> | Redo |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete selected pages |
| <kbd>Ctrl/Cmd+D</kbd> | Duplicate selected pages |
| <kbd>Ctrl/Cmd+L</kbd> | Rotate selected pages 90° left |
| <kbd>Ctrl/Cmd+R</kbd> | Rotate selected pages 90° right |
| Click | Select page |
| Shift+click | Select range to the last-selected page |
| Ctrl/Cmd+click | Add/remove a single page to/from the selection |
| Double-click a page | Toggle focus mode |
| Right-click a page | Duplicate / rotate / delete |
| Right-click a document header | Save / close |
| <kbd>Ctrl/Cmd+/</kbd> | Show this overview |

On Windows/Linux, `Cmd` corresponds to `Ctrl`; on macOS, `Ctrl` in a
click/gesture context is reserved by the OS for its own secondary-click
convention, so use `Cmd` there for the click-based shortcuts above.
