mirrors the same list shown in the app itself (Options → Info → Licenses &
acknowledgments, sourced from `src/acknowledgments.mjs`).

|---|---|---|
| [PageBoard](LICENSE) | MIT | This project. |

| [@tabler/icons](https://github.com/tabler/tabler-icons) | MIT | A handful of icon outlines were hand-copied as path data into `src/icons.mjs` — see that file for details. |
